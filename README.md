# آموزش نظریه زبان‌ها و ماشین‌ها

### معرفی پروژه

این مخزن با هدف انتشار آموزش‌ها، یادداشت‌ها و مثال‌های کاربردی در زمینه نظریه زبان‌ها و ماشین‌ها ایجاد شده است.

مطالب این مجموعه با تمرکز بر یادگیری مفاهیم، ارائه مثال‌های کاربردی و مستندسازی دانش نظریه محاسبات تهیه می‌شوند.

### پیش‌نیازهای آموزش

برای درک بهتر مطالب این مخزن، آشنایی با سه حوزه زیر ضروری است.

**۱. ریاضیات گسسته**

نام انگلیسی: ‎Discrete Mathematics‎

- نظریه مجموعه‌ها
- روابط و توابع
- استقرا و اثبات
- گراف‌ها و درخت‌ها

**۲. ساختمان داده و الگوریتم**

نام انگلیسی: ‎Data Structures and Algorithms‎

- آرایه‌ها و لیست‌ها
- پشته و صف
- درخت‌ها
- گراف‌ها و پیمایش

**۳. مبانی برنامه‌نویسی**

نام انگلیسی: ‎Programming Fundamentals‎

- ساختارهای کنترلی
- توابع بازگشتی
- پیچیدگی الگوریتمی
